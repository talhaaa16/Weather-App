# Weather App

A minimalist **Weather Application** that fetches real-time weather metrics using the **OpenWeatherMap API**. It offers an instant overview of temperature, humidity, and weather conditions worldwide.

### 🚀 Quick Start
1. **Clone & Install:**
   ```bash
   git clone <repo-url> && cd weather-app && npm install
   ```
2. **Set API Key:** Create a `.env` file in the root directory:
   ```env
   VITE_WEATHER_API_KEY=your_api_key_here
   ```
3. **Run App:** Launch the local development environment:
   ```bash
   npm run dev
   ```
